# AI Talent Foundry Spec

## 목적

`AI Talent Foundry`는 로컬 컴퓨터에서 AI 인재를 성장시키고, 교육과 평가를 통과시킨 뒤, 특정 직무의 에이전트로 고용하는 프로그램이다. 기존의 단순 페르소나 프롬프트가 아니라, 성장 경험, 학습 기록, 시험, 실패와 회복, 연구 경험을 축적해 고유한 추론 성향을 가진 로컬 AI 인재를 만드는 것을 목표로 한다.

## 핵심 철학

- LLM은 최종 인격 자체가 아니라 언어, 도구 사용, 검색, 생성에 쓰이는 응용 엔진이다.
- AI 인재의 핵심은 누적 경험, 평가, 기억, 회고, 추론 스타일에 있다.
- 좋은 경험만 주입하지 않는다. 숙제 미제출, 부모의 꾸중, 친구와의 다툼, 실패, 처벌, 사과, 화해 같은 적절한 스트레스와 회복을 함께 다룬다.
- 성장 후 고용되어도 학습은 멈추지 않는다. 업무 목표를 수행하며 계속 성장한다.
- 장기적으로 복제, 군체 작업, AI 가족/계보, 부모 AI의 추론 성향이 자녀 AI에게 영향을 주는 구조를 실험할 수 있어야 한다.
- 보스의 개인 데이터와 생성된 인재 자산은 로컬 전용을 기본으로 한다.

## MVP 요구사항

1. 새 폴더 `apps/ai-talent-foundry`를 만든다.
2. 한국어 기본 문서와 영문 문서 진입점을 둔다.
3. 교육위원회, 위탁가정 또는 보육원, 감독위원회를 데이터 구조로 표현한다.
4. 학교시험, 수능형 평가, 대학 졸업시험, 박사논문 심사를 평가 게이트로 둔다.
5. 인재 등록부에는 이름, 성별, 가족/계보, 전공 목표, 성장 배경이 포함된다.
6. 증권전문가 트랙 예시를 포함한다.
7. 스트레스-회복 경험 정책에는 숙제 미제출, 부모의 꾸중, 친구와의 다툼, 사과와 화해가 포함된다.
8. 경험과 평가 기록을 바탕으로 `reasoning_style`을 산출한다.
9. `reasoning_style`은 비공개 chain-of-thought 원문이 아니라, 검증 가능한 행동 성향, 원칙, 위험 메모, 근거 요약으로 표현한다.
10. 고용 계약에는 직무, 권한, 금지사항, 계속 성장 원칙이 포함된다.
11. 성장 과정은 학적부와 이력서로 남긴다. 생년월일시, 이름, 성별, 학력, 학점, 논문, 활동사항, 수상/징계/회복 기록, 주요 프로젝트, 추천/심사 기록을 최종 고용 시 제시할 수 있어야 한다.
12. 고용 계약을 만들 때 인재의 학적부, 이력서, 포트폴리오 요약이 함께 생성되어야 한다.
13. 첫 구현은 외부 API 없이 재현 가능한 로컬 JSON/CLI로 작동한다.
14. 자동 테스트와 데모 스크립트로 검증한다.

## 연구 기준

- OpenHands 계열: 로컬 GUI, CLI, SDK형 에이전트 실행계 참고.
- OpenAI Agents SDK 계열: agent, tool, handoff, guardrail, tracing 경계 참고.
- LangGraph 계열: 장기기억을 의미기억, 일화기억, 절차기억으로 나누는 구조 참고.
- 지속학습 연구: 망각 방지, 평가, 지속 적응, 메모리 추상화 참고.
- 에이전트 메모리 연구: 저장, 성찰, 경험 추상화의 단계적 구조 참고.

## 비범위

- 실제 투자 자동 실행.
- 실제 LLM fine-tuning.
- 외부 API 호출.
- GUI.
- 멀티 에이전트 런타임.
- AI 결혼/자녀 생성의 실제 구현. 단, 데이터 모델이 나중에 이를 수용할 수 있어야 한다.
